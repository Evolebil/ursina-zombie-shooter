# Zombie Shooter - 3D Игра на Python + Ursina

Простой 3D zombie shooter на Python с использованием **Ursina 8.3.0** и **Panda3D**.

## Установка

### Требования
- Python 3.7+

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Evolebil/ursina-zombie-shooter.git
cd ursina-zombie-shooter
```

2. Создайте виртуальное окружение (опционально, но рекомендуется):
```bash
python -m venv venv
# На Windows:
venv\Scripts\activate
# На macOS/Linux:
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install -r requirements.txt
```

4. Запустите игру:
```bash
python game.py
```

## Управление

### Движение и камера
- **W/A/S/D** — движение вперёд/влево/назад/вправо
- **Мышь** — вращение камеры
- **Пробел** — прыжок

### Боевой геймплей
- **ЛКМ (левая кнопка мыши)** — стрельба из текущего оружия
- **1** — переключиться на Пистолет
- **2** — переключиться на Дробовик
- **3** — переключиться на Автомат

## Характеристики оружия

### Пистолет (1)
- Урон: 20
- Лучей: 1
- Задержка: 0.2 сек
- Разброс: маленький

### Дробовик (2)
- Урон: 35
- Лучей: 8
- Задержка: 0.8 сек
- Разброс: большой

### Автомат (3)
- Урон: 10
- Лучей: 1
- Задержка: 0.05 сек
- Разброс: маленький

## Враги

### Зомби
- **HP:** 100
- **Скорость:** 2.5 м/с
- **Атака:** 1 HP урона каждую секунду при приближении
- **Спавн:** вокруг игрока на расстоянии 5-15 м

### Сложность
- Начальный интервал спавна: 2 сек
- Интервал уменьшается с каждым убийством (минимум 0.5 сек)
- Игра становится сложнее по мере прохождения

## Игровые механики

### Здоровье игрока
- **HP:** 5
- Каждая атака зомби отнимает 1 HP
- UI показывает текущее и максимальное здоровье

### Game Over
- Когда HP достигает 0, игра прерывается
- Показывается экран Game Over с количеством убитых зомби
- Кнопка "Играть снова" полностью перезапускает игру

### Счётчик убийств
- Увеличивается на 1 за каждого убитого зомби
- Влияет на сложность (интервал спавна)

## Решение проблем

### Игра не запускается
1. Проверьте, что установлены все зависимости: `pip install -r requirements.txt`
2. Убедитесь, что используется Python 3.7 или выше
3. На Linux может потребоваться установка дополнительных библиотек графики

### Низкий FPS
- Это нормально для простого движка Panda3D
- Попробуйте уменьшить количество врагов или разрешение
- Закройте ненужные программы

### Проблемы с мышью/камерой
- Нажмите ESC для захвата/отпуска мыши
- Переместите окно и повторите попытку
